# 使用说明

> 先读 [RED-LINES.md](RED-LINES.md)（使用红线），再看本文。
> 本文按「从零到能用」的顺序写，遇到问题直接跳到第 9 节排错。

---

## 1. 你需要什么

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows / macOS / Linux 均可 | 有现代浏览器就行 |
| 浏览器 | Chrome / Edge / Firefox 最新版 | 语音识别（STT）目前**只有 Chromium 系**（Chrome / Edge）支持，Firefox 下语音输入不可用，其余功能正常 |
| Node.js | **≥ 18**（推荐 20/22） | 只用来起本地静态服务器，不参与运行时 |
| DeepSeek API Key | 可选 | 不填也能玩桌宠和互动，只是不能聊天 |

不需要：`npm install`、构建工具、GPU、Python（除非你自己部署训练后端）。

---

## 2. 安装与启动

### 2.1 拿到代码

```bash
git clone <你的仓库地址> aemeath-desktop-pet
cd aemeath-desktop-pet
```

或者直接下载 ZIP 解压。

### 2.2 启动

```bash
node tools/serve.mjs
```

看到这样的输出就成功了：

```
爱弥斯桌宠已启动：http://127.0.0.1:18340/
静态根目录: D:\...\aemeath-desktop-pet\web
按 Ctrl+C 停止。
```

浏览器打开 **http://127.0.0.1:18340/**。

常用参数：

```bash
node tools/serve.mjs --port 8080        # 换端口
node tools/serve.mjs --host 0.0.0.0     # 让同局域网设备也能访问（注意：同网段的人都能打开）
node tools/serve.mjs --help             # 看帮助
```

### 2.3 ⚠️ 为什么不能直接双击 index.html

本项目用**原生 ES Module**（`<script type="module">`）。浏览器在 `file://` 协议下会以 CORS 为由拒绝加载模块，页面会白屏、控制台报 `Access to script ... has been blocked by CORS policy`。

这不是 bug，是浏览器的安全策略。**必须走 http。**

   💬                 │  训练面板（Ctrl+3）      │

### 3.1 跟桌宠玩

## 4. 让它能聊天（DeepSeek）

### 4.1 拿 Key

到 [platform.deepseek.com](https://platform.deepseek.com/) 注册并在「API Keys」里创建一个，形如 `sk-xxxxxxxx`。

### 4.2 填进插件

1. 按 `Ctrl+4` 打开**设置**。
2. 「DeepSeek 接入」区块：
   - **API Key**：粘进去。输入框失焦时会提示「已保存到本次会话」。
   - **Base URL**：默认 `https://api.deepseek.com`，一般不用改。用第三方中转就改成中转地址。
   - **模型**：默认 `deepseek-chat`。想要推理模型可改 `deepseek-reasoner`（回复会更慢更长）。
3. 点**「测试连接」**。
   - 成功：`✅ 320ms · deepseek-chat` + 一条回复。
   - 失败：会打印 HTTP 状态码和响应体，按第 9 节排错。

### 4.3 开始对话

按 `Ctrl+1` 回到聊天面板，输入框里打字，`Enter` 发送（`Shift+Enter` 换行）。

- 回复是**流式**的，逐字往外蹦；想打断就点 **⏹ 停止**。
- 右上角有个 **🔊 朗读**开关：打开后每条回复会用语音念出来，念的时候小爱嘴会动。
- **🗑 清空**：清空当前对话与本地记录。

### 4.4 关于 API Key 的存储（重要）

| 问题 | 答案 |
|---|---|
| 存哪？ | 浏览器 `sessionStorage`，键名 `aemeath.secret.chat.apiKey` |
| 会写进 `localStorage` 吗？ | **不会**。刷新页面就要重填——这是故意的安全设计 |
| 会上传到别处吗？ | 只作为 `Authorization: Bearer` 头发给你填的那个 Base URL |
| 会被导出吗？ | **不会**。「设置 → 数据与隐私 → 导出设置」明确排除所有密钥 |
| 会写进代码吗？ | **不会**。仓库里没有任何硬编码 Key |

## 5. 语音对话

### 5.1 说话给她听（STT，语音 → 文字）

⚠️ 需要 **Chrome 或 Edge**（Web Speech API 的识别部分在 Firefox 下不可用）。

两种用法：

- **按住说话**：语音面板里按住「按住说话」，说完松开。松手即发。
- **连续聆听**：点「开始连续聆听」，就一直听，每次识别到完整句子就自动发出去。再点一次停止。

识别过程中的**中间结果**会实时显示在面板的转写框里，不用等说完。

> 首次使用浏览器会弹麦克风授权，必须允许。需要 `https://` 或 `localhost` —— 我们用的是 `127.0.0.1`，属于安全上下文，没问题。

### 5.2 让她说话（TTS，文字 → 语音）

三种后端，在**语音面板**的「语音输出」里选：

| 后端 | 说明 | 需要配置吗 |
|---|---|---|
| `browser`（默认） | 浏览器内置 `speechSynthesis`。开箱即用，零配置 | 不用 |
| `http-openai` | OpenAI 兼容的 `/v1/audio/speech` | 需要填端点 + 模型 + 音色 +（可选）Key |
| `http-gptsovits` | GPT-SoVITS 风格的 `/tts` 或 `/inference` | 同上 |
| `http-edge` | Edge-TTS 风格的端点 | 同上 |

**浏览器音色**：下拉框会列出你系统里所有可用音色。中文系统一般有「Microsoft 晓晓 / 云希」等。不选就自动挑最合适的中文音色。

**音调 / 语速 / 音量**：三个滑块，实时生效，右侧会显示当前数值。

> 默认 `pitch` 是 1.35（偏高、偏幼），配合 Q 版形象。想要正常一点就调到 1.0。

### 5.3 自检

语音面板底部的**「语音自检」**会返回一份 JSON，报告：浏览器支持情况、可用音色数量、各 TTS 后端是否可用、STT 是否可用。排查问题时先点它。

## 6. 训练一版「你自己的」声音

> **这一节必须配合 [RED-LINES.md](RED-LINES.md) 一起看。**
> 只能用**你自己的声音**，或你已取得**明确书面授权**的声音素材。

### 6.1 流程总览

```
你的录音 ──→ voice-training/data/
                  │
                  ├─ node voice-training/scripts/make-manifest.mjs     生成清单
                  ├─ node voice-training/scripts/validate-dataset.mjs  校验
                  │
                  └─→ 你自己的训练后端（GPT-SoVITS / Bert-VITS2 / 云端 API）
                              │
                              └─→ 在插件的「训练」面板填端点地址提交任务
                                          │
                                          └─→ 拿到模型 → 在语音面板接上你训好的端点
```

### 6.2 录音要求（简版，详见 `voice-training/SCHEMA.md`）

| 项 | 要求 |
|---|---|
| 格式 | WAV / FLAC（无损或有损高质量） |
| 采样率 | ≥ 16000 Hz（推荐 22050 或 44100） |
| 声道 | 单声道 |
| 单条时长 | 3–15 秒 |
| 数量 | **≥ 10 条**（校验通过的下限；建议 50–200 条、总时长 5–30 分钟。想效果像样，10 分钟起步） |
| 内容 | 语速自然、情绪平稳、覆盖常用音素；避免背景音乐、混响、爆音 |
| 命名 | 见 SCHEMA.md（不要用真名，用 `speaker-a_0001.wav` 这类） |

### 6.3 用插件里的训练面板

「训练」面板（`Ctrl+3`）做的是**对接**，不是训练本身：

1. 先勾选「**我已确认素材权利归属**」（不勾不让提交，这是强制的）。
2. 拖入或选择你的音频文件 —— 面板会**逐个探测**并显示时长 / 采样率 / 声道 / 峰值 dB。任何一项不达标会标红。
3. 点「**校验清单**」看结构化结果（errors / warnings / stats）。
4. 点「**下载清单模板**」拿到 JSON 模板，按 `voice-training/SCHEMA.md` 填好。
5. 填「**训练后端端点**」（你自己部署的服务地址），点「提交任务」。
6. 端点没填时不会静默失败，会明确提示 `no-endpoint`。

**本插件不自带训练算力。** 三种可选路线（GPT-SoVITS / Bert-VITS2 / 云端 API）的操作步骤见 `voice-training/scripts/README.md`。

### 6.4 训好之后怎么用

把训练后端部署起来（它会暴露一个 HTTP 端点），回到**语音面板**：

1. 「语音输出」选 `http-gptsovits`（或 `http-openai`，看你的后端接口形态）。
2. 填端点地址、模型名、音色名。
3. 点「自检」确认可用，然后让她说句话试试。

## 7. 设置项逐条说明

### 7.1 桌宠

| 项 | 说明 |
|---|---|
| 大小 | 0.6×–1.6× 缩放 |
| 鼠标跟随 | 关掉后视线不跟着你的鼠标转（省 CPU） |
| 降低动效 | 关掉大部分动画，适合晕动症或低配机器 |
| 重现位置 | 把桌宠挪回右下角默认位置 |
| 播放全部动作 | 依次演示 12 种动作，用来确认动画都正常 |

### 7.2 聊天

| 项 | 默认 | 说明 |
|---|---|---|
| 模型 | `deepseek-chat` | 也可 `deepseek-reasoner` |
| 温度 | 1.3 | 越高越发散。1.3 适合角色扮演；想稳一点调到 0.8 |
| 最长回复 | 1024 | token 上限 |
| 流式输出 | 开 | 关掉就等全部生成完再显示 |
| 超时 | 60s | 超时自动中断 |
| 人设预设 | 活泼陪伴 | 4 个原创预设，见 [PERSONA.md](PERSONA.md) |
| 记住对话 | 开 | 关掉则刷新后不恢复历史 |
| 保留轮数 | 20 | 发给模型的上下文轮数（省 token） |
| 自动朗读 | 关 | 打开后每条回复自动念 |

### 7.3 语音

见第 5 节。另有：

| 项 | 说明 |
|---|---|
| 识别语言 | 默认 `zh-CN`，可改 `en-US` / `ja-JP` 等 |
| 连续识别 | 关掉则每次只识别一句 |
| 回复后自动聆听 | 打开后像打电话一样自动接话（谨慎开，可能自我循环） |

### 7.4 界面

| 项 | 说明 |
|---|---|
| 主题 | 自动 / 深色 / 浅色 |
| 紧凑模式 | 缩小间距，适合小屏 |

## 8. 隐私与数据

| 数据 | 存在哪 | 离开本机吗 |
|---|---|---|
| API Key | `sessionStorage`（关标签页失效） | 只发给你配置的端点 |
| 对话内容 | `localStorage`（键 `aemeath.kv.chat.history`） | 发给 DeepSeek |
| 桌宠位置 | `localStorage`（`aemeath.kv.pet.pos`） | 不会 |
| 偏好设置 | `localStorage`（前缀 `aemeath.prefs.`） | 不会 |
| 训练音频 | 你的磁盘 `voice-training/data/` | 只发给你配置的训练后端 |

**一键操作**（设置 → 数据与隐私）：

- **导出设置**：下载 JSON（明确**不含任何密钥**）
- **清空聊天记录**
- **恢复默认设置**（不动密钥）

想彻底重置：关掉标签页（清 sessionStorage）+ 浏览器里清 `127.0.0.1` 的站点数据。

## 9. 排错

### 9.1 页面白屏 / 控制台报 CORS

**原因**：直接双击了 `index.html`。
**解法**：用 `node tools/serve.mjs` 起服务，访问 `http://127.0.0.1:<端口>/`。

### 9.2 提示「模块未加载」

某个 `web/js/<模块>/index.js` 缺失或被杀毒软件删了。看浏览器控制台的 `[aemeath:app] 模块 xxx 加载失败` 具体报错。设置面板底部「关于 → 调试信息」会显示各模块状态（✓/✗）。

### 9.3 聊天报错

| 现象 | 原因 | 解法 |
|---|---|---|
| `401 Unauthorized` | Key 错 / 过期 / 前后有空格 | 重新粘贴，注意别带换行 |
| `402 Insufficient Balance` | DeepSeek 账户余额不足 | 充值 |
| `429 Too Many Requests` | 触发限速 | 等一会，或降 `max_tokens` |
| `Failed to fetch` / CORS | 网络不通，或 Base URL 不支持浏览器直连 | 检查网络；换支持 CORS 的端点 |
| 一直转圈到超时 | 网络慢 / 长回复 | 调大「超时」，或换 `deepseek-chat` |
| 回复里出现「作为一个AI」 | 模型越界 | 已有人设后处理，仍出现就在人设描述里加强约束（见 PERSONA.md） |

### 9.4 语音不工作

| 现象 | 原因 | 解法 |
|---|---|---|
| 点麦克风没反应 | 不是 Chromium 系浏览器 | 换 Chrome / Edge |
| 连续聆听立刻停 | 麦克风权限被拒 | 地址栏左侧图标里允许麦克风 |
| 没有声音 | 系统音量 / 音色不支持 | 点「语音自检」看可用音色；换个音色试试 |
| 声音很怪 | 浏览器 TTS 音质有限 | 正常现象。想要好音质就自己训练 + 接外部端点 |
| 嘴不动 | 浏览器 TTS 无边界事件 | 已用定时估算兜底；若仍不动，检查控制台 |

### 9.5 `node tools/serve.mjs` 报端口占用

```bash
node tools/serve.mjs --port 18341
```

### 9.6 桌宠不见了

- 可能被拖到屏幕外了：设置 → 桌宠 → **重现位置**。
- 可能缩得太小：把「大小」调回 1.0。
- 按 `F12` 看控制台有没有 `[aemeath:app] PetUI 挂载失败`。

### 9.7 想更彻底地排查

```bash
node tools/selfcheck-dom.mjs    # 检查 HTML 与 JS 的契约是否一致
node --test tests/*.test.mjs    # 跑单元测试
```

浏览器控制台里执行 `__AEMEATH_DEBUG__`（若模块提供了 `getDebugState()`）可以拿到 fps、动作计数、当前 mood。

## 10. 卸载

1. 删掉整个 `aemeath-desktop-pet` 目录。
2. 浏览器里清掉 `127.0.0.1:<端口>` 的站点数据（清 `localStorage` / `sessionStorage` / 麦克风权限）。
3. 如果训了模型：删掉你的训练后端目录与 `voice-training/data/`。

没有注册表项、没有常驻进程、没有后台服务。`Ctrl+C` 关掉那个 `node` 就是彻底停掉。

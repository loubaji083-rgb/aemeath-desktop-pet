## 2. 你可以放心做的事（允许范围）

- ✅ 用**你自己的声音**录音，训练一个属于你自己的语音模型，自己玩。
- ✅ 用你**已获得明确书面授权**的声音素材做训练。
- ✅ 用**无版权/CC0/你自己合成**的音源做训练。
- ✅ Fork 本仓库，改形象、改人设、改 UI，做你自己的原创桌宠。
- ✅ 在技术博客/视频里讲解实现原理（请保留免责声明链接）。

## 3. 声音训练功能的真实定位

`voice-training/` 目录是一个**流程骨架**，它提供：

- 数据集规范（`voice-training/SCHEMA.md`）
- 纯 Node 校验脚本（`voice-training/scripts/validate-dataset.mjs`）
- 清单生成脚本（`voice-training/scripts/make-manifest.mjs`）
- 训练后端对接接口（`web/js/training/index.js` 的 `submitJob/pollJob`）

它**不提供**：任何预训练权重、任何声线、任何音频文件、任何一键克隆能力、任何算力。

换句话说：**本插件给你一把空工具箱，工具要你自己准备，素材权利要你自己确认。**

声音训练（自备数据）

      
    


    

      

        红线声明
        
本插件内置的是训练工具链，不是训练好的声音。仓库不提供任何预训练模型、权重或音频素材。

        
请只使用你本人的声音，或已获得书面授权的声音素材。未经许可克隆他人声音，在中国受《民法典》第 1023 条（声音参照肖像权保护）约束，在日本受声优「声の権利」与事务所条款约束，在多数平台也违反服务条款。

        
      


      
    
        
  1. 
          
    1. 准备数据
    
          
    单声道、≥16kHz、3–15 秒/条、低底噪、无混响。放到 voice-training/data/<说话人>/，该目录已被 .gitignore 排除，不会进仓库。
    
          
          
        
    2. 

        
  2. 
          
    2. 挑选并校验音频
    
          
          
    
          
        
    3. 

        
  3. 
          
    3. 提交训练任务
    
          
    本插件不自带训练算力。请自行部署训练后端（见 voice-training/scripts/README.md 的三种路线），然后在下面填一个 HTTP 端点。
    
          
    
            
            
            
            
            
          
    
          
          
    
        
    4. 

        
  4. 
          
    4. 接回插件
    
          
    训练完成后，在「语音面板 → 提供方」选择对应的 HTTP 端点，把地址指向你的推理服务即可。插件本身不搬运权重。
